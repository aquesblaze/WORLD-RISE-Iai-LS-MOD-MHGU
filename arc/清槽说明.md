# GU 世界太刀（无敌帧判定按 v1.1）

基础：合并版源码（登龙命中闪光用第二版 + 公会太刀下劈红线 + 全风格 + 居合纳刀循环 + 震动）。
新增：从「R 大回旋开刃清槽-不加无敌帧」移植的**大回旋开刃后清空气刃槽**。
新增：**无敌帧判定与「公会太刀 v1.1」一致**（bit26 源窗口，不加不减帧）。

## 新增内容

1. **连段大回旋开刃后清空槽**：`c/world_core.c` 两处开刃结算（`w_leave()` 与逐帧结算）
   在置 `rank_delta=1`、`gauge_clear=1` 的同时加 `gauge_hold=4`，
   `combine()` 取较大值。
2. **原生开刃也清槽**：`c/world_adapter.inc` 每帧读 `actor+0x3330`（气刃等级，
   原生开刃函数 `0x119ed98` 就是对该字段 +delta），一旦上升就清槽并保持 4 帧：
   ```c
   int rank_now=(int)word(a,0x3330);
   if(rank_now>world_rank_seen){ world_gauge_hold=4; put(a,0x2780,0); set_real(a,0x3334,0); }
   ```
   保持 4 帧是防止同一段窗口里招式自身的练气获取把槽又加回来。
3. `c/world_core.h`：`WDecision` 增加 `gauge_hold` 字段；切场景/换玩家时重置基准值。

## 无敌帧判定（按 v1.1）

c/world_adapter.inc 的 world_damage()：

`c
unsigned iai=(world.move==W_SMALL||world.move==W_BIG)&&e&&(e->common&0x04000000u);
`

- 当前帧所在 TIML 事件的 common bit26 置位即无敌（把待处理攻击包 +0x31e0 清零）；
- 事件是跨度，窗口 = 从 bit26 事件开始到下一条非 bit26 事件为止：
  小居合 5 帧、大居合(白/黄) 12 帧、大居合(红) 14 帧；
- 不做 +2 延后、也不做 −2 剪短（之前那套 last-2 已删除）。

## 登龙腾空按 R 下劈

c/world_command_driver.inc：W_RISE 只负责记录“R 已松开”，
只有 W_AIR（腾空）分支会真正触发：

`c
if(!(b->held&ML_R))s->helm_air_armed=1;          // 松开过 R 才“武装”
if(s->helm_air_armed&&(b->held&ML_R)){           // 再按 R
    s->helm_air_armed=0;return enter(s,o,W_DOWN,ML_R);
}
`

- WState 新增 helm_air_armed；enter(...,W_RISE,...) 时清 0，保证一次腾空只认一次新按键；
- 起跳段（W_RISE）**不会**触发下劈，避免提前取消起跳；
- 腾空后（W_AIR，且 frame>=1）按 R 才下劈；
- 不按 R 时行为完全不变（仍按源 TIML 的自动窗口下劈）；
- 起跳时若 R 还按着（R+X 出突刺），要先松开再按才生效。

## 勇气蓝刃 → 红刃判定

c/world_follow.inc 捕获延迟伤害弹时，原生气刃等级 4 及以上（勇气蓝刃）按 3（红刃）取弹种：

`c
unsigned tier=helm?world_helm_tier:world.rank;
if(helm&&tier>3){ tier=3; log_event(world_helm_tier_red, ...); }
`

c/world_adapter.inc 进登龙时同步记录 world_helm_tier=world.rank>3?3:world.rank;。
伤害（source 1000+tier）与气刃回复（红刃 15）都按红刃走；其它风格本来就是 0-3，不受影响。

## 原始功能（未改动）

- 登龙命中闪光 = 第二版（`0x3f61 + 序号%3`）
- 下劈垂直红线 = 公会太刀 v1.1（`0x3f81` + `0x3f82/83/84` 尾迹）
- 全风格可用；居合纳刀循环（任意帧 R+B，0.5 秒宽限）
- 震动：居合 GP 命中 0.35 秒 / 登龙命中跟随击中特效
- 居合无敌帧按源数据（不加帧）
