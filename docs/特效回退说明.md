# 登龙 / 居合「命中闪光与特效」回退说明（v1.0.7 改版）

## 目标

官方 v1.0.7 重做了登龙与大居合的特效：
- 大居合第一段的额外命中闪光被删除；
- 弹壳命中改为「每个延迟命中播放一次 helm_impact（0x3fc0）」，并抑制原生命中视觉；
- 居合第二段刀线改成新版 EFL（平滑淡出），并且把原来的多组小特效合并成 0x3fc0-0x3fc6。

本改版把这两招的命中闪光与特效换回较早的**公会太刀（v1.0.1 线，R 键连续居合那版）**实现，
其余内容保持 v1.0.7 不变。

## 改法

### 1. 特效资源库合并（world_simple_fx.arc）

两版 arc 的格式是 `<4sHHI` 头（"ARC\0", 17, 条目数, 0）+ 80 字节条目 + zlib 负载：

- 条目：`<64s path><u32 kind><u32 压缩长度><u32 原始长度|0x40000000><u32 负载偏移>`
- 负载：`zlib.compress(raw, 9)`

合并规则：

- 保留 v1.0.7 的全部 96 个条目（突刺/看破/新特效原样不动）；
- 追加旧版独有的 79 个条目（旧闪光 flash_3f65/3f66-3f68/3f7c/3f7d/3f83、旧刀光
  iai_line_helm_3f80/3f81/3f82/3f84、飞屑 fleck_*、glow_* 等）；
- 3 个内容不同的居合刀线 EFL（`iai_line_e10_0`、`iai_line_e10_rank3`、`iai_line_e11_0`）
  采用**旧版**，恢复旧刀线外观；
- 根表 `effect/pel/pl/world_simple`（PEL，uid→特效载荷）按 uid 合并：旧版 68 条 + 新版独有
  17 条 = **85 条**，旧 uid（0x3f60-0x3f88）与新 uid（0x3fc0-0x3fc6）都能解析，无重复 uid。

合并后条目数 **96 + 79 = 175**，`c/world_simple_fx_assets.h` 的
`WORLD_SIMPLE_FX_COUNT` 同步改为 175（插件启动时用它校验资源库条目数）。

### 2. 代码：换回旧版实现

| 文件 | 改动 |
| --- | --- |
| `c/world_helm_iai_fx.inc` | 用旧版实现替换：`world_fx_hit()`（每壳原生命中闪光 0x3f61-0x3f63）、`world_helm_line()`（落地刀光 0x3f81）、`world_big_fx_tick()`（大居合整组旧特效） |
| `c/world_simple_fx.inc` | 恢复 `world_helm_line_pending` / `world_helm_tail_pending` 状态与 `world_fx_begin` 复位；`world_fx_tick` 增加落地刀光与两批尾焰（0x3f84/0x3f83/0x3f82） |
| `c/world_follow.inc` | `world_burst()` 末尾加回旧版「首个弹壳出刀光 + 每壳命中闪光」；怪物查询里去掉 `world_helm_impact()`（保留命中音与日志）；去掉弹壳命中视觉抑制 `collider+0x52=0` |
| `c/world_adapter.inc` | 前置声明改为 `world_fx_hit` / `world_helm_line` |
| `c/world_simple_fx_assets.h` | `WORLD_SIMPLE_FX_COUNT 175u` |

登龙命中音（EPV 25530）、兜割延迟命中音、突刺/看破的 `world_tf_tick` 与
`world_particle_dynamics`、音频与其它 v1.0.7 行为均未改动。

## 未验证项

- 未进游戏实测；只做了编译、arc 结构自检（条目/uid 解析、负载 zlib 往返）与机器码核对。
- 旧版特效依赖原生效果载荷（cm121 等），若某些场景下旧闪光不出现，属于效果系统未注册该 uid，
  可按日志确认后单独调整。
